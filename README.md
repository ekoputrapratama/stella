# Stella 🌟

## The All-in-One Android Power Tool

Stella is a comprehensive Qt5 based utility designed for advanced Android users, developers, and enthusiasts. It streamlines complex device management tasks—from simple backups to deep system modifications—into a single, intuitive interface.

### 🚀 Features

- Backup & Restore: Full partition and data backups to keep your device safe before experimentation.

- Screen Mirroring: High-quality, low-latency mirroring of your Android screen to your desktop.

- OEM Unlocker: Automated scripts to assist in unlocking bootloaders across various manufacturers.

- Rooting Suite: One-click style rooting helpers for compatible devices.

- ROM Flasher: A safe environment to flash custom recoveries (TWRP/OrangeFox) and custom ROMs.

---

### 🛠 Tech Stack

Framework: Qt Framework (C++), Python 3

Communication: ADB (Android Debug Bridge) & Fastboot

Platform: Windows / Linux / macOS
